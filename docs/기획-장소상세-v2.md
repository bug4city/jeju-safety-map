# 장소 상세 카드 v2 기획

작성일: 2026-08-25 · 대상: `index.html`의 `renderSafetyCard` / `openMapPlaceInspector` 흐름

## 1. 문제 정의

사용자는 "이 장소가 얼마나 안전한가"를 보러 오는데, 현재 카드는:

- 데이터가 4줄(붐빔도·보도 사건·지역 순위·유동인구)뿐이고, 이미 갖고 있는 CCTV·도움 장소 데이터조차 카드에 안 나온다.
- 장소의 시각 정보(사진/거리뷰)가 없어 "여기가 어디인지" 감이 안 온다.
- 공유가 텍스트 한 줄 + 고정 링크라, 받은 사람이 눌러도 그 장소로 이동하지 않는다.

톤 원칙 유지: **"안전 판정"이 아니라 공개 데이터를 한 곳에 모아 보여주는 참고 자료.** 종합 점수(스코어링)는 만들지 않는다.

## 2. 데이터 확장

### 2.1 이미 가진 데이터로 즉시 추가 (P0)

| 지표 | 소스 | 카드 표기 |
|---|---|---|
| 주변 CCTV | `data/cctv.json` `points[]` | "반경 500m 내 CCTV N곳 · 카메라 M대", 생활방범 목적 수 별도 표기, 최근접 거리 |
| 최근접 경찰서 | `showNearestHelp` 로직 재사용 (PO3, 폴백 `FALLBACK_HELP_PLACES`) | "OO지구대 · 1.2km" + 지도이동 버튼 |
| 최근접 병원(응급) | 동일 (HP8) | "OO병원 · 800m" |
| 사건 상세 리스트 | `incidents.json` | 8km 내 사건이 있으면 건수만이 아니라 제목·날짜·상태·출처 링크를 접이식 목록으로 |
| 편의점 밀도 | Kakao `categorySearch` CS2, radius 500 | "도보권 편의점 N곳" (심야 불빛/대피처 프록시) |

CCTV 근접 계산은 이미 로드된 `state.cctv.points`를 haversine으로 필터하면 되고 추가 fetch가 없다.

### 2.2 데이터 파이프라인 확장 (P1)

- **시간대별 유동인구**: `build_pop.py`가 쓰는 제주 생활인구 API에 시간대 파라미터가 있는지 확인 → 있으면 `pop.json`에 `night`(22~06시) 필드 추가. 카드에 "심야 유동인구" 표기. 심야 한적/붐빔이 사용자의 실제 질문("밤에 걸어도 되나")에 가장 가깝다.
- **범죄주의구간 등급 조회**: 현재 WMS 픽셀 오버레이만 있음. 같은 safemap 레이어의 `GetFeatureInfo` 요청으로 클릭 지점의 등급을 받아 "생활안전 주의구간: N등급 / 해당 없음" 텍스트화. 실패 시 항목 숨김(카드 blocking 금지).
- **여성안심 시설·안전비상벨·가로등**: 공공데이터포털에 제주 데이터셋 존재 여부 확인 후 `tools/build_*.py` 패턴으로 정적 JSON 추가. 있으면 "반경 500m 내 비상벨 N개" 등.

### 2.3 하지 않는 것

- 종합 안전 점수/등급 산출 (판정 오해 + 법적 리스크)
- 실시간 데이터 (서버 없음 유지)

## 3. 장소 이미지

Kakao Places API는 사진을 주지 않으므로:

1. **(P0) 카카오 로드뷰 썸네일**: Roadview API로 해당 좌표 파노라마 존재 확인 → 카드 상단에 로드뷰 미니뷰(정적 스냅샷 불가하므로 소형 `Roadview` 인스턴스 or 탭하면 전체화면). 파노라마 없으면 영역 자동 숨김.
2. **(P0) 미니맵 스냅샷**: 카드 상단에 해당 지점 중심 정적 미니맵(마커+주변 CCTV 점). 이미지 저장 시 카드에 같이 캡처되어 공유 이미지 품질도 올라감.
3. **(P2) 장소 사진**: 카카오맵 place URL(`place.map.kakao.com/{id}`)로 "카카오맵에서 사진 보기" 외부 링크만 제공. 크롤링/무단 사용 금지.

## 4. UI 개편

현행: 제목 → 칩 2개 → 표 3줄 → 버튼 3개. 위계가 평평하고 시각 요소가 없다.

### 새 레이아웃 (위→아래)

1. **헤더**: 장소명 + 카테고리 뱃지 + 주소, 우측에 로드뷰/미니맵 썸네일 (없으면 텍스트만)
2. **핵심 스탯 타일 4개** (2×2 그리드, 기존 칩 스타일 확장)
   - 보도 사건 (8km) — 없음이면 brand green, 있으면 accent
   - 지역 붐빔도 — 기존 5분위 팔레트
   - CCTV (500m) — `--cctv` 색
   - 도움 장소 — 최근접 경찰/병원 거리
3. **펼침 상세 (아코디언)**: 사건 목록·CCTV 목적 구성·지역 순위·유동인구 수치·(P1) 심야 유동인구
4. **출처 푸터**: 기존 문구 유지 + 데이터 기준일 per-소스 표기
5. **공유 버튼 줄**

### 규칙

- 토큰(`--sp-*`, `--fs-*`, 기존 팔레트)만 사용, 신규 색 금지. 스탯 타일은 `MapPlaceInspector` 명세로 `DESIGN.md`에 추가.
- 로딩: 현재 텍스트 로딩 문구 → 스켈레톤 타일 4개.
- 복사 버튼 "복사됨!" 라벨 2초 후 원복 (현재 원복 안 됨 — 버그 수준).
- 카드가 길어지므로 모바일 시트에서 내부 스크롤 확인.

## 5. 공유 개편

### 5.1 딥링크 (P0, 가장 중요)

- URL 파라미터 `?lat=&lng=&name=` 지원: 진입 시 파라미터 있으면 해당 지점으로 이동 + 카드 자동 오픈.
- 모든 공유(카톡/복사)의 링크를 고정 홈이 아닌 이 딥링크로 교체. **받은 사람이 눌렀을 때 같은 카드가 뜨는 것**이 공유 기능의 핵심 가치.

### 5.2 카톡 공유 (P0)

- `objectType: 'text'` → `'feed'`로 교체.
- 이미지: html2canvas로 캡처한 카드 PNG를 `Kakao.Share.uploadImage()`(카카오 제공, 서버 불필요, 20일 보관)로 업로드 → 반환 URL을 feed `imageUrl`에 사용. 업로드 실패 시 기존 text 폴백.
- 본문: 장소명 + 핵심 지표 2줄, 버튼 "이 장소 확인하기" → 딥링크.

### 5.3 기타

- **Web Share API** (P1): `navigator.canShare({files})` 지원 모바일에서는 "공유" 버튼 하나로 이미지 파일+딥링크 동시 공유 (인스타 DM 등 카톡 외 채널 커버).
- **이미지 저장 개선** (P0): 캡처 대상에 새 헤더(미니맵 포함) 포함, 파일명에 장소명 (`제주안전지도_삼화도담어린이집.png`).
- GA: `card_share`에 `method: 'webshare'` 추가, 딥링크 유입 `card_deeplink_open` 이벤트 추가.

## 7. 리스크

- `config.json`에 API 키가 평문 커밋되어 있음 — 공유 트래픽 늘기 전에 도메인 제한 확인 필수.
- Kakao uploadImage는 앱 설정(플랫폼 도메인 등록) 필요 — jeju.kimyukah.com 등록 확인.
- 카드 항목이 늘수록 "판정처럼 보일" 위험 — 각 지표에 출처·기준일을 항목 단위로 붙여 참고자료 톤 유지.
