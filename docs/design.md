# 제주 안전지도 디자인 시스템

네이버 지도 스타일의 "조용한 배경 + 카드 UI + 단일 액센트" 원칙을 따르는 미니 디자인 시스템.
모든 토큰은 `index.html`의 `:root`에 CSS 변수로 정의되어 있고, **색·간격·타이포는 반드시 토큰만 사용한다.**

## 원칙

1. **색은 의미를 진다.** 지도 위의 색은 데이터(사건, 붐빔도)만 표현하고, UI 색(브랜드)은 데이터 색과 절대 겹치지 않는다.
2. **배경은 조용하게.** 패널·칩·범례는 흰 카드 + 옅은 그림자. 시선은 지도 데이터로 간다.
3. **단일 액센트.** 인터랙션(선택·링크·버튼)은 브랜드 초록 하나로만 표현한다.

### 다크 테마

`html[data-theme="dark"]`에서 **토큰만 재정의**한다 (개별 컴포넌트에 다크 분기 금지). 저장값(localStorage `theme`) 우선, 없으면 `prefers-color-scheme`. 렌더 전 `<head>` 부트스트랩 스크립트가 적용해 깜빡임을 막는다.

- 지도 타일은 다크 스타일이 없어 `#map`에 `brightness(.82)`만 적용.
- 지도 위 마커·핀의 흰 배경은 가독성 때문에 라이트 고정 — 의도된 예외.
- 공유 카드 캡처는 항상 라이트: `onclone`에서 `data-theme`을 제거하고 `.capturing`을 입힌다.

### 붐빔도 데이터 팔레트 (5단계, 한적→붐빔)

`popStyle()`(index.html)과 범례 그라데이션 두 곳에 정의 — 바꿀 때 **둘 다** 갱신할 것.

`#d35400`(가장 한적) → `#f0a35e` → `#d9d4c5` → `#7fa8d9` → `#2a5ca8`(가장 붐빔)

- 주황→파랑 조합은 색약에도 안전하다.
- **초록 계열 금지**: 초록은 브랜드 전용이라 데이터 색으로 쓰면 오독된다.
- 정의 위치: `popStyle()`(JS)과 CSS `.legend .scale-pop` 그라데이션 — 바꿀 때 **둘 다** 갱신.

### 범죄주의구간 범례 그라데이션

`.legend .scale-crime`: `#ffe27a → #f5a623 → #e2573b → #b81d13`. 실제 지도 레이어는 행안부 WMS 래스터라 색을 서버가 그린다 — 범례는 근사치이며 WMS 스타일이 바뀌면 함께 조정.

### 지도 데이터 레이어 예외 색 (JS 내)

읍면 폴리곤 외곽선 `#8e8e93`, 데이터 없음 채움 `#ccc`, 클러스터 `rgba(192,57,43,.95)`(=`--accent` 계열). 지도 캔버스 전용이라 CSS 토큰을 못 쓰는 의도된 예외.

## 간격 토큰

4단계 스케일만 사용한다. 임의의 px 간격을 새로 만들지 않는다.

| 토큰 | 값 | 용도 예 |
|---|---|---|
| `--sp-1` | 4px | 제목-부제 사이 등 미세 간격 |
| `--sp-2` | 8px | 리스트 행 상하 패딩, 요소 사이 기본 간격 |
| `--sp-3` | 12px | 행 내부 가로 gap, 문단 아래 여백 |
| `--sp-4` | 16px | 패널 좌우 패딩 (헤더·탭·본문 정렬선 통일) |

## 타이포 토큰

시스템 폰트(-apple-system, Apple SD Gothic Neo, Pretendard).

| 토큰 | 값 | 용도 |
|---|---|---|
| `--fs-title` | 17px | 패널 제목, 상세 제목 |
| `--fs-md` | 15px | 헤더 브랜드, 지도 사건 마커 주 텍스트 |
| `--fs-body` | 14px | 본문, 리스트 제목, 버튼 |
| `--fs-ui` | 13.5px | 탭, 칩, 카드 행 |
| `--fs-sub` | 12.5px | 보조 설명, 리스트 부제 |
| `--fs-cap` | 11px | 캡션, 게이지 숫자, 출처 표기 |

### 타이포 역할 (상세·카드 화면)

상세/카드 화면의 모든 텍스트는 아래 6개 역할 중 하나로만 조판한다. 새 요소를 추가할 때 새 크기 조합을 만들지 않는다.

| 역할 | 조판 | 적용 예 |
|---|---|---|
| 화면 제목 | `--fs-title` bold `--ink` | `.detail h2` |
| 메타 | `--fs-sub` `--sub` | 주소(`.addr`), 분류·순위 줄(`.area`) |
| 본문 요약 | `--fs-body` 1.65 `--ink`, 강조만 `<b>` | `.summary-text` |
| 섹션 라벨 | `--fs-cap` 700 `--sub` letter-spacing .2px | `.context-box span`, `.near-regions h4`, `.route-row > span`, `.quiet-top-label` |
| 값 | `--fs-body`(박스)·`--fs-ui`(행) 700 `--ink` | `.context-box b`, `.row b` |
| 캡션 | `--fs-cap` `--sub` | `.context-box small`, `.src-caption`, `.split-ends` |

행(`.row`)의 라벨 span은 `--sub`, 값 b는 `--ink` — 박스와 같은 라벨/값 위계를 유지한다.

### 블록 리듬

상세/카드 안의 블록(요약, 인사이트, 비율 바, 박스 그리드, 행 묶음, 가까운 지역, 길찾기, 접기)은 **모두 `--sp-3`(12px) 세로 간격**으로 쌓는다. 블록 내부 요소 간격은 `--sp-1`~`--sp-2`. 특정 블록만 `--sp-2`나 임의 값으로 붙이지 않는다.

## 형태·그림자 토큰

| 토큰 | 값 | 용도 |
|---|---|---|
| `--r-xs` | 6px | 배지, 상태 태그, 태그칩, 푸트노트 |
| `--r-sm` | 10px | 탭, 버튼, 입력창, 범례 |
| `--r-lg` | 16px | 패널, 안전 카드 |
| `--shadow-1` | `0 1px 6px rgba(0,0,0,.1)` | 칩, 범례, 라벨 등 지도 위 소형 요소 |
| `--shadow-2` | `0 4px 20px rgba(0,0,0,.14)` | 패널, 플로팅 버튼, 토스트 |

칩과 플로팅 버튼은 `border-radius:999px`(필) 형태를 쓴다.

## 컴포넌트 규칙

- **탭 선택**: `--brand-soft` 배경 + `--brand` 글자·테두리 (틴트 스타일)
- **칩 선택**: `--brand-soft` 틴트 배경 + `--brand` 글자·테두리 (솔리드 채움은 CTA 전용 — 지도 위 토글이 지도를 이기지 않게)
- **사건 표시**(핀·클러스터·배지·리스트 점): 항상 `--accent` 빨강
- **붐빔도 표시**(폴리곤·라벨·게이지·태그칩): 항상 `popStyle().color()` 반환값
- **공공 CCTV 표시**(카메라 아이콘·라벨·범례): 항상 `--cctv` 청록
- **링크·뒤로가기**: `--brand`
- **인사이트 박스**(`.insight`): 기본 `--brand-soft`, 사건 경고는 `.alert`(`--insight-alert-bg` + `--accent` 글자). 상세당 1개만 — 패널의 주인공이므로 다른 강조 박스를 옆에 두지 않는다
- **도민/외지인 비율 바**(`.split-bar`): 도민 `--blue`, 외지인 `--cctv`. 바 + 캡션 한 줄로만 표기
- **상세 모드**: 상세가 열리면 `#panel.detail-mode`가 목록 전용 컨트롤(정렬 칩·결과 메타·동네 TOP)을 숨긴다
- **공유 카드**: 패널에서는 `.safety-card`를 상자 없이 펼치고, 카드 테두리·"안전 점검" 제목·브랜드 줄은 캡처 시 `.capturing`에서만 보인다
- **길찾기 버튼**: 카카오 `#fee500`·네이버 `#03c75a`·티맵 `#e0287c` — 외부 브랜드 색 예외
- **도움 장소 박스**(`.help-box`): 그리드 전체 폭. 장소마다 한 줄 — 이름(잉크 700, 지도 이동 버튼) 왼쪽, 종류·거리 캡션 오른쪽. 반폭 박스에 넣어 개행시키지 않는다
- **박스 라벨/값/캡션 셀렉터는 직계 자식(`>`)으로만**: `.context-box span`처럼 자손 전체에 걸면 박스 안 컴포넌트(도움 장소 등) 스타일을 덮어쓴다
- 예외적으로 카카오 공유 버튼만 카카오 브랜드 노랑 `#FEE500` 유지
